设计概览 Overview

FinDesign 是一套专为金融数据产品打造的蓝白色调设计系统，灵感来源于专业级股票分析终端。系统以「信任感、专业度、数据可读性」为核心目标，通过克制的蓝白主色搭配深黄辅助，构建出冷静理性的金融视觉语言。所有 Token、组件、模式均经过实盘场景验证，可直接用于股票分析、量化研究、投资组合管理、行情看板等金融 Web 产品。

设计原则 Design Principles
数据优先 Data First

所有视觉决策服务于数据可读性。数字使用 JetBrains Mono 等宽字体确保对齐，关键指标采用大字号 + 渐变色突出，避免装饰性元素干扰信息密度。

信任质感 Trust & Premium

深蓝主色 + 白色卡片 + 柔和阴影构建专业感，深黄用于提醒 / 警告等场景，强化注意力引导。玻璃拟态顶栏与渐变背景营造层次。

语义清晰 Semantic Clarity

遵循中国市场红涨绿跌惯例，配合 tag-up / tag-down / tag-neutral 三态标签，让用户在 0.5 秒内识别趋势方向。等级徽章 S/A/B/C 形成直观评分梯度。

克制动效 Restrained Motion

动效仅用于状态反馈与注意力引导：shimmer 进度条暗示实时计算、pulse 脉冲点标记在线状态、fadeInUp 入场动画。避免无意义装饰性动画。

色彩系统 Colors

色彩系统遵循「App 前端三色约束」：红 / 绿 / 蓝（各分浅中深）+ 深黄辅助。蓝色 #0b5fff 为主色，承担品牌识别与主要交互；红色 #e54d5e 用于上涨与危险；绿色 #18a058 用于下跌与成功；深黄 #c89020 用于提醒。中性色采用蓝灰调（而非纯灰），与主色形成统一色温。语义色遵循中国市场红涨绿跌惯例。

字体系统 Typography

字体系统采用三族协作策略：Noto Sans SC 作为正文与 UI 主字体，覆盖中英文混排；JetBrains Mono 用于所有数字、代码、股票代码，等宽特性保证数据列对齐；Orbitron 仅用于品牌标识、大号评分数字与等级徽章，其几何感与未来感强化「量化、科技、专业」的品牌调性。三者权重梯度从 300 到 900，覆盖从辅助说明到强调标题的全部场景。

阴影系统 Shadows

遮罩与焦点环 Overlay & Focus Ring

遮罩层用于模态框、抽屉等浮层组件的背景遮蔽，采用半透明深色叠加配合高斯模糊，在弱化背景内容的同时保持视觉层次。焦点环用于键盘导航时的可访问性标识，3px 宽度配合主色半透明填充，确保焦点状态清晰可见且不干扰内容。

按钮 Buttons

按钮系统提供 5 种语义变体（primary / secondary / ghost / accent / gold / danger）与 3 种尺寸（sm / md / lg）。主按钮采用蓝色渐变 + 光泽扫过动效，用于核心操作；次按钮白底蓝边用于辅助操作；幽灵按钮用于工具栏；金色按钮严格限定在会员升级、稀缺资源等场景。

动效系统 Motion

Shimmer · 进度条流光

Pulse · 脉冲点
