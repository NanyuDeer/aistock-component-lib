# 组件库开发指南

> 组件库由林晓研负责，通过 vibecoding 让 AI 辅助开发。
> AI 开发助手请先读 `AGENTS.md`（入口规则），再读本指南（详细规范）。
> 视觉规范的唯一参照是 `design/` 目录下的 HTML 设计稿。

---

## 仓库结构

| 目录 | 作用 |
|------|------|
| `src/components/` | 组件本体，每个 `.vue` 文件是一个组件 |
| `src/styles/variables.scss` | Design Token 变量（与设计稿一一对应） |
| `src/index.ts` | 统一导出入口，每完成一个组件在这里登记 |
| `dev/App.vue` | 本地预览页面，引入组件看效果 |
| `design/` | HTML 设计稿，视觉规范的唯一参照 |

## 本地预览

```bash
pnpm install    # 首次安装依赖
pnpm dev        # 启动预览，浏览器打开看组件效果
pnpm type-check # 类型检查
```

预览环境已配置：`view`/`text` 等标签识别为自定义元素，`rpx` 自动转 `vw`，`variables.scss` 全局注入。写完组件在 `dev/App.vue` 引入即可预览。

## 组件开发规范

### 标签与单位

- 标签用 `view`/`text`/`image`/`scroll-view`，不用 `div`/`span`/`img`（uni-app 跨端要求）
- 尺寸用 `rpx`，不用 `px`
- 事件用 `@tap`，不用 `@click`

### 命名

- 文件名：大驼峰，一个组件一个文件，如 `Card.vue`、`EmptyState.vue`
- 类名：统一 `as-` 前缀 + 短横线，如 `as-card`、`as-btn--primary`
- Props 名：小驼峰，如 `title`、`showHeader`
- 事件名：小写连字符，如 `@click`、`@change`

### 样式

- `<style lang="scss" scoped>` 必须加 `scoped`
- 所有颜色、字号、间距、圆角、阴影用 `variables.scss` 里的变量，禁止硬编码
- 设计稿里出现的值，去 `variables.scss` 找对应变量名；如果没有，找尹辰补充
- A 股涨跌色：红涨绿跌，`$stock-up-color`（红）/ `$stock-down-color`（绿），不要搞反

### 图标

- 禁用 emoji，统一用 SvgIcon 组件加载 SVG
- SVG 文件放 `src/static/assets/icons/`，命名用短横线如 `bell-line.svg`

### Props 写法

```vue
<script setup lang="ts">
withDefaults(defineProps<{
  title?: string              // 可选字符串
  count?: number              // 可选数字
  type?: 'primary' | 'danger' // 可选限定值
  showHeader?: boolean        // 可选布尔
}>(), {
  title: '',
  count: 0,
  type: 'primary',
  showHeader: true
})
</script>
```

带 `?` 的可选 Props 都要在 `withDefaults` 第二个参数给默认值。

## 组件示例

参照 `aistock-app-frontend/src/shared/components/` 下已有组件的写法（Card.vue、Button.vue、EmptyState.vue 等），迁移到本仓库并改用 Design Token 变量。

一个最小卡片组件示例：

```vue
<template>
  <view class="as-card">
    <view v-if="title" class="as-card-header">
      <text class="as-card-title">{{ title }}</text>
    </view>
    <view class="as-card-body">
      <slot />
    </view>
  </view>
</template>

<script setup lang="ts">
withDefaults(defineProps<{
  title?: string
}>(), {
  title: ''
})
</script>

<style lang="scss" scoped>
.as-card {
  background: $bg-color-grey;
  border-radius: $radius-base;
  padding: $spacing-base;
  box-shadow: $shadow-base;
}
.as-card-title {
  font-size: $font-size-lg;
  font-weight: 600;
  color: $text-color-title;
}
.as-card-body {
  width: 100%;
}
</style>
```

## 导出登记

每完成一个组件，在 `src/index.ts` 登记：

```ts
export { default as Card } from './components/Card.vue'
export { default as Button } from './components/Button.vue'
```

## 协作流程（PR）

组件库采用 Pull Request 流程，main 分支受保护：

1. 从 main 拉最新：`git checkout main && git pull`
2. 建开发分支：`git checkout -b feat/组件名`
3. 写组件代码
4. 提交：`git add src/components/Card.vue && git commit -m "feat: 新增 Card 组件"`
5. 推送：`git push -u origin feat/组件名`
6. GitHub 网页发 PR（base: main ← compare: feat/组件名）
7. 等尹辰 review，有反馈就改了再推，有冲突找尹辰帮解决
8. 合并后清理：`git checkout main && git pull && git branch -d feat/组件名`

提交信息规范：`feat:`（新增）/ `fix:`（修复）/ `docs:`（文档）/ `style:`（样式），后接一句话说明。

## 遇到问题

- 设计稿里的值在 `variables.scss` 找不到对应变量 → 找尹辰补充
- Git 冲突不会解决 → 截图发尹辰，不要瞎选
- 其他任何问题 → 截图发尹辰

*组件库技术栈以 App 前端（uni-app + Vue 3 + TypeScript + SCSS + rpx）为准。网页前端（aistock-frontend）通过 Design Token 变量共享设计规范。*
