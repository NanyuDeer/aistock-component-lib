## 1. 快速开始

### 安装

```bash
pnpm install aistock-component-lib
```

### 全局注册

```ts
// main.ts
import { createApp } from 'vue'
import App from './App.vue'
import * as AsComponents from 'aistock-component-lib'

const app = createApp(App)
// 批量注册
for (const [name, component] of Object.entries(AsComponents)) {
  app.component(name, component as never)
}
app.mount('#app')
```

### 按需引入

```vue
<script setup lang="ts">
import { Button, Card, StockItem } from 'aistock-component-lib'
</script>
```

## 2. 基础 UI 组件

### Button 按钮

```vue
<Button type="primary" size="md" @click="handleClick">确认</Button>
```

| Prop | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| type | `primary \| secondary \| ghost \| accent \| gold \| danger` | `primary` | 按钮样式 |
| size | `sm \| md \| lg` | `md` | 按钮尺寸 |
| disabled | `boolean` | `false` | 禁用状态 |
| loading | `boolean` | `false` | 加载中状态 |

| Event | 参数 | 说明 |
|-------|------|------|
| click | `(event: MouseEvent)` | 点击事件 |

### Card 卡片

```vue
<Card title="趋势股评分" subtitle="技术面分析" hoverable>
  <p>卡片内容</p>
  <template #footer>底部内容</template>
```

| Prop | 类型 | 默认值 | 说明 |
|------|------|--------|------|

| subtitle | `string` | `''` | 副标题 |
| hoverable | `boolean` | `false` | 悬浮效果 |

| Slot | 说明 |
|------|------|
| default | 卡片内容 |
| extra | 标题右侧附加区域 |
| footer | 底部区域 |

## 8. 通用 UI 扩展组件

### Collapse 折叠面板

```vue
<Collapse v-model:open="open" title="公告详情">此处为折叠内容…</Collapse>
```
Props：`title?`、`open?`（v-model:open，默认 false）、`disabled?`。Events：`update:open`、`change`。

### Pagination 分页

```vue
<Pagination v-model:current="page" :total="85" :page-size="10" @change="onPage" />
```
Props：`current?`（v-model，默认 1）、`total`、`pageSize?`（默认 10）、`prevText?`、`nextText?`。Events：`update:current`、`change`。

### Timeline 时间线

```vue
<Timeline :items="[{ time:'2026-08-01', title:'半年报披露', status:'success' }]" mode="left" />
```
Props：`items: { time; title; desc?; status?: 'primary'|'success'|'warning'|'danger' }[]`、`mode?: 'left'|'right'|'alternate'`（默认 left）。

### Result 结果页

```vue
<Result status="success" title="买入成功" subtitle="已成交 100 股">
  <Button type="primary">查看持仓</Button>
</Result>
```
Props：`status?: 'success'|'warning'|'error'|'info'`、`title?`、`subtitle?`。Slot：default（操作区）、icon。

### PeriodSelector 周期选择器

```vue
<PeriodSelector v-model:value="idx" :periods="['分时','日K','周K']" @change="onPeriod" />
```
Props：`periods?`（默认 `['分时','5日','日K','周K','月K']`）、`value?`（v-model，默认 0）。Events：`update:value`、`change`。

## 11. 金融业务深组件

### QuoteHeader 行情头

Props：`items: { name; price; changePct }[]`、`speed?`（默认 30 秒）。CSS 无缝滚动，hover 暂停。

### AnnounceCard 公告研报卡片

```vue
<AnnounceCard type="research" title="宁德时代市占率分析" source="中信证券" time="2026-08-01" summary="…" @click="onDetail" />
```
Props：`type?: 'announce'|'research'`、`title`、`source?`、`time?`、`summary?`。Slot：default、footer。Events：`click`。

```vue
<Watchlist :items="list" editable @remove="onRemove" @click="onPick" />
```
Props：`items: { name; code; price; changePct }[]`、`editable?`。Slot：action（scoped `{ item, index }`）。Events：`remove`、`click`。

### RadarChart 雷达图

```vue
<RadarChart :dimensions="[{label:'成长',value:82},{label:'估值',value:45}]" :size="360" status="primary" />
```
Props：`dimensions: { label; value; max? }[]`、`size?`（默认 400 rpx）、`status?: 'primary'|'success'|'warning'|'danger'|'gold'`。SVG 绘制，空数据显示空态。

### RelationGraph 关系图谱

```vue
<RelationGraph :nodes="nodes" :links="links" direction="vertical" />
```
Props：`nodes: { key; label; category?: 'core'|'upstream'|'downstream' }[]`、`links: { from; to; label? }[]`、`direction?: 'vertical'|'horizontal'`。SVG 树状图，空数据显示空态。

## 11.5 洞见标志组件

> 洞察之眼系统：全站"洞见"入口统一使用的标志性组件，瞳孔即洞见类型，独立于通用组件库风格。

### InsightTag 洞见标签

```vue
<InsightTag type="emotion">情绪洞见</InsightTag>
<InsightTag type="market" size="lg">市场洞见</InsightTag>
```
Props：`type?: 'emotion'|'fund'|'event'|'market'`（默认 emotion）、`size?: 'sm'|'md'|'lg'`（默认 md）。
瞳孔语义：虚线外环=数据流，虹膜渐变=数据汇聚，瞳孔+高光=AI 看穿本质。瞳孔颜色即类型：情绪红 / 资金金 / 事件青 / 市场蓝。

### InsightCard 洞见卡片

```vue
<InsightCard
  type="emotion"
  title="市场情绪降至冰点"
  trace="跌停家数显著增加，抛压集中释放"
  forecast="情绪回暖概率大，短线或迎反弹窗口"
  time="08-21 · 09:10"
  show-meta
  confidence="0.82"
/>
<!-- 深蓝研报卡 -->
<InsightCard type="market" title="放量上攻" trace="北向资金净流入" forecast="维持强势" theme="dark" show-meta />
```
Props：`type?`、`title`（结论一句话）、`trace`（溯源）、`forecast`（预判）、`time?`、`theme?: 'light'|'dark'`（默认 light）、`showMeta?`、`confidence?`。Events：`click`。
结构规范：瞳孔标签置前 → 结论 → 溯源 → 预判（两句话上限）。

## 13. 常见问题

### Q: 如何在 uni-app 项目中使用？

组件已按 uni-app 规范编写（view/text/image/scroll-view 标签 + rpx 单位），直接安装引用即可。

### Q: A 股涨跌色怎么用？

```scss
// 上涨用红色
color: $up;     // #e54d5e

// 下跌用绿色
color: $down;   // #18a058
```

### Q: 如何自定义主题色？

修改 `src/styles/variables.scss` 中的 `$primary` 变量即可，所有组件自动生效。

### Q: 可以只引入部分组件吗？

可以，按需 import 即可：

```ts
import { Button, Card } from 'aistock-component-lib'
```

### Q: 组件支持暗色模式吗？

当前版本为蓝白浅色主题，暗色模式将在后续版本支持。
